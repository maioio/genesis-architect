# Genesis Architect — Documentation

> Genesis Architect is an **AI Engineering Partner**: it understands, researches,
> decides, builds, secures, tests, recovers, and improves software projects
> across their full lifecycle. The homepage explains it in 30 seconds; this is
> the depth.

This documentation is the **technical truth layer**. No marketing fluff — what
each engine does, where the Free/Pro line falls, a worked example, and sample
output.

**Three intelligence layers** (the language used throughout):

| Layer | Meaning |
|-------|---------|
| **Engineering Source Intelligence** | Official docs, source code, security DBs, packages — the authoritative truth. |
| **Research Intelligence** | The pipeline that plans research, ranks evidence, and produces Evidence Packs. |
| **Developer Field Intelligence** | What practitioners actually hit in the field (Stack Overflow, Reddit, HN, YouTube) — verified against stronger sources, never treated as final truth. |
