How it works

Research first. Then build.

Every other scaffolder starts from a template. Genesis starts from production data.

Phase 01
🔍

Scan real repos

Finds 15 GitHub repos building exactly what you described. Ranks by stars and active fork activity.

Phase 02
⚠️

Mine closed issues

Reads up to 20 closed bug issues per repo from the top 5 ranked repos. Extracts recurring errors, security patches, architecture regrets.

Phase 03
🧬

Synthesize ecosystem

Builds the "wise average" — what successful projects converge on — not a copy of one repo.

Phase 04
🏗️

Generate + validate

Creates scaffold with tests and CI/CD. Runs smoke test. Never declares success without exit code 0.

Free core

Not a template.
A research pipeline.

Built for developers who've been burned by boilerplate that doesn't survive contact with production.

🔬

Real Issue Mining

Reads closed bug issues from production repos. Finds the feedparser hang, the Redis connection leak, the Celery task that silently drops — before you write the code.

🍴

Smart Fork Analysis

Finds the top 3 active forks ranked by merged PRs in the last 6 months — not stars. Extracts bug fixes and incorporates them into your pitfall list.

🗄️

Knowledge Vault

Caches solutions locally with 6-month TTL and LRU eviction at 500 entries. Runs fast on repeat projects. Falls back to Stack Overflow on cache miss.

💬

Natural Language Choices

Say "I want the simple one" instead of typing A. Genesis maps natural language to architecture choices — no memorizing option letters.

🤖

Companion Mode

Run genesis companion after scaffolding. Stays active, answers questions, detects when you've moved on.

🔌

Works with any LLM

Claude, GPT-4, Gemini, Ollama — all supported via LiteLLM. Set your key once with genesis config set LLM_API_KEY.

0–100 score across Modularity, Coupling, Cohesion, Layering. 6 adaptive profiles. Trend history in .genesis/score_history.jsonl.

🕸️

Anti-Pattern Detector PRO

7 structural anti-patterns: God Class, Hub File, Circular Deps, Dead Code (free core) plus Feature Envy, Leaky Abstraction, Shotgun Surgery (Pro). Pure graph — no LLM.

🔥

Fragility Classifier PRO

VOLATILE / FRAGILE / STABLE per module. Combines anti-patterns + git churn + test coverage. Outputs FRAGILITY_MAP.md with GO / HOLD / REWRITE.

📋

Refactoring Planner PRO

Tier-1 critical first, tier-2 improvements after. Each step includes operations, complexity estimate, and projected score impact.

🗺️

C4 Diagrams PRO

Levels 1–2 (System Context, Containers) in free core; Level 3 (Components) in Pro. Mermaid output — renders natively on GitHub. Auto-detects databases, auth, queues, payments.

🔗

Knowledge Graph PRO

Links code, CVEs, risks, and decisions into one queryable graph. Answers: "which do-not-touch zone has an open CVE?" No other tool does this.

Genesis Decision Engine

One command. Seven modes.
Twelve safety gates.

The GDE routes any plain-English instruction to the right engines — deterministically, without an LLM guess. Two gates can never be bypassed.

Stage 01
📥

INTAKE

Classify intent from free text. Signal-based, sub-millisecond. No LLM call.

Stage 02
🗺️

PLAN

Topological sort across engines. Parallel grouping for concurrent execution.

Stage 03
⚙️

EXECUTE

Engines run phase by phase. Optional engines degrade gracefully on failure.

Stage 04
🚦

GATE

12 named gates. 2 hard blocks that can never be overridden by any flag.

Stage 05
📋

REPORT

Confidence score, risk level, decision log. Session persists — resume anytime.

Stage 06
✅

APPROVE

Inspect all pending write operations before any file is touched.

Stage 07
💾

COMMIT

Atomic tmp → rename writes. Parent directories auto-created.
