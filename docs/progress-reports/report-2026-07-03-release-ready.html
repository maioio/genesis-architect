מה נשאר לך לעשות (פעולות ידניות — לא קוד)

  • הפוש לאתר (origin/main) ה-build החדש של landing page מחכה ב-/tmp/genesis-main-wt. הרץ: cd /tmp/genesis-main-wt && git push origin main
  • Tauri signing key (לפני release) npx tauri signer generate -w ~/.tauri/genesis-companion.key → העתק pubkey ל-tauri.conf.json plugins.updater.pubkey → הוסף TAURI_SIGNING_PRIVATE_KEY ל-GitHub Secrets
  • App icon — החלפה בלוגו Genesis האמיתי npx tauri icon genesis_architect_logos/genesis_architect_blue_300dpi.png (מייצר כל הגדלים אוטומטית, מעדכן src-tauri/icons/)
  • Windows Authenticode cert (לפני GA) ללא זה: SmartScreen מציג "Unknown Publisher". לא חוסם, אבל פוגע ב-UX. ראה companion/docs/code-signing.md — DigiCert EV cert, ~$350/yr.
  • Apple Developer Program (לפני macOS launch) $99/yr. ללא זה: Gatekeeper מחסום. הוראות ב-companion/docs/code-signing.md.
  • VS Code publisher account + VSCE_PAT פתח account ב-marketplace.visualstudio.com/manage → publisher: "genesis-pro" → קבל PAT → הוסף VSCE_PAT ל-GitHub Secrets
