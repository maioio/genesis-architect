How it works

A scaffold that remembers what broke.

The difference from a template: the output reflects failures from real production projects, each tied to a concrete task.

  1. Find

    Locates 15 to 20 repositories solving the problem you described, filtered by stars, recency and language.

  2. Mine

    Reads their closed issues for recurring failures, security patches and architecture regrets.

  3. Synthesize

    Keeps what survived in production across those projects, with sources and a confidence grade.

  4. Act

    Turns each pitfall into a code task, not a document to read later.

Capabilities

Everything ships in one package.

ScaffolderNew projects with tests, CI/CD and security defaults generated from the research.
ResearchA registry of 30 sources across 11 tiers, ranked by recency and corroboration. Docs and local code rank highest.
Codebase intelligenceImport graph for Python, TypeScript/JavaScript, Go and Rust. Cycle detection, anti-patterns, drift against a committed model, fragility classification.
SecuritySTRIDE threat model, OWASP checklist, offline secrets scanning with redaction, CVE lookup through OSV.dev without an API key.
Decision engineSeven modes routed from plain language, behind a 14-gate policy table.
CommitteeFive advisors using different reasoning methods, synthesized into one answer.

Install

One command.

Free, AGPL-3.0, Python 3.11 or newer, no telemetry by default. A commercial license is available for closed-source use.

# install
pip install genesis-architect

# new project
genesis init a Python CLI for analyzing log files

# existing code
genesis recover .
genesis harden .

# ask in plain language
genesis decide "why is this project so hard to change?"
