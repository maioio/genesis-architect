## Language rules

- Use the three intelligence-layer names: **Engineering Source Intelligence**,
  **Research Intelligence**, **Developer Field Intelligence**.
- Do **not** name Instagram (or any social platform) as a core technical source.
  Field intelligence is a *market signal* tier; engineering truth comes from
  docs/source/security. Primary named field sources: GitHub, Stack Overflow,
  Reddit, Hacker News, YouTube.
- No marketing fluff that the docs would contradict. The homepage promises;
  the docs prove.

## Do NOT

- Ship any Pro code to the public repo.
- Claim UI features (Floating Assistant / Canvas) as available — they are
  planned. Mark them "coming" if mentioned at all.
