# Archive

Point-in-time documents: release notes for versions that are no longer current,
launch copy, roadmaps that have since been delivered or abandoned, and one-off
validation reports.

They are kept because the CHANGELOG references several of them by name, and
because a claim about what a release contained is worth being able to check.
They are **not** maintained. Anything here may describe a paid tier that no
longer exists, a module that has been renamed, or a plan that was dropped.

For current material see [ARCHITECTURE.md](../../ARCHITECTURE.md),
[CHANGELOG.md](../../CHANGELOG.md) and the
[README](../../README.md).
