What Phase 3 Wired

TypeScript Panel → Bubble IPC Bridge

The Panel window owns the WebSocket connection. After every decoded event, it now mirrors it to the Bubble window via Tauri's native IPC (emit("genesis://event")). Connection state changes (auth.ok / WS close) are separately bridged via genesis://connection. Bubble's Zustand store stays perfectly in sync without ever touching the WebSocket directly.

  • src/ws/ipc_bridge.ts — bridgeEvent() + bridgeConnection()
  • src/ws/client.ts — calls bridge after every handleEvent() and on connect/disconnect
Python Gate Resume Flow (approve → commit)

Previously InboundRouter._run_gde() would run a GDE session and emit session.done — but never actually commit approved changes. Now it implements the full 5-step gate resume flow:

gde.run()
→
emit gate.approval_required
→
emit diff.ready
→
PendingGate.wait(300s)
→
gde.approve() + commit()
  • HARD_BLOCK → emits session.done immediately, no approval prompt
  • BLOCK → builds HTML diff preview from pending writes, waits up to 5 min for UI decision
  • Approval arrives via _handle_approval() which sets the threading.Event
  • Timeout (5 min) → auto-defer, writes stay pending in .genesis/
Python IDE Bridge Hot-Swap After GDE Run

InboundRouter._update_ide_bridge() is called after every GDE run (regardless of gate outcome). It rebuilds the pattern index from engine output and calls ide_bridge.update_index() so the VS Code extension immediately sees fresh hints for the new analysis.

  • build_index_from_engine_results() extracts anti-patterns + fragility findings
  • Index passed to IDEBridgeServer via its update_index(session_id) method
  • gde_cli.py now passes ide_bridge into both cmd_companion_serve and cmd_companion_ui
TypeScript / React Voice PTT — Web Audio → STT → GDE

VoicePTT.tsx gives the user a push-to-talk button in the Panel. It captures mono 16 kHz PCM via Web Audio API, encodes it to WAV in-browser, converts to base64, and sends it via sendVoiceEnd(audioB64) over WebSocket. The Python InboundRouter transcribes it (faster-whisper) and runs GDE.

  • ScriptProcessorNode collects Float32 PCM chunks at 4096 samples per callback
  • Custom encodeWav() — pure browser, no dependencies, produces valid PCM WAV
  • States: idle → recording (animated red dot) → processing → idle
  • Live transcript shows as italic grey text below the button
  • Degrades gracefully: mic denied → error message; STT unavailable → error event from Python
