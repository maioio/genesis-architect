# What Genesis Is

Genesis Architect is an **AI Engineering Partner**. Not just a code generator,
not just a search tool — a partner that helps you become a better builder by:

- **finding what already exists** before you reinvent it,
- **learning from real failures** other engineers hit,
- **making evidence-based decisions** instead of guesses,
- **improving the project continuously** across its whole life.

## The lifecycle it covers

```
idea → research → architecture → decisions → build → secure → test →
recover → improve → maintain
```

Most tools cover one slice. Genesis runs the whole loop and remembers what it
learned for next time.

## Two tiers, one product

- **Free (`genesis-architect`)** — a complete, genuinely useful tool: it
  researches GitHub and scaffolds a working project, and exposes core
  architecture analysis (import graph, basic score, core anti-patterns, basic
  C4).
- **Pro (`genesis-architect-pro`)** — the intelligence layer on top: deep
  research, Developer Field Intelligence, Recovery, drift detection, the
  Decision Engine, cross-session Memory, the Knowledge Graph, and more.

Pro **extends** Free; it does not cripple it. See [Free vs Pro](04_free_vs_pro.md).

## What makes it different

The flagship capability neither competing tool has: **cross-source connective
intelligence** — code + field reports + security + decisions linked in one
[Knowledge Graph](25_knowledge_graph.md), so Genesis can answer questions like
*"which do-not-touch zone has an open CVE?"* or *"did a Reddit warning predict
this drift?"*
