# Site prototypes (historical)

These are design studies for an earlier landing page, kept as a record. They are not the
current site and do not describe the current product.

- They were written while Genesis was still open-core, so several pages show a paid "Pro"
  tier, a price and a purchase link. **There is no paid tier** (since v8.0.0).
- `genesis.html` is the Genesis study. The other pages (`bun`, `clerk`, `mercury`, `prisma`,
  `railway`, `raycast`, `supabase`) are style explorations and are unrelated to Genesis content.
- `_build.py` generated them. `DESIGN_SYSTEM.md` is the brief they were built from.

The current site is built from [`site/`](../../../site/).

The leading underscore in this folder name keeps Jekyll (GitHub Pages' legacy build) from
publishing these pages. Do not rename it.
