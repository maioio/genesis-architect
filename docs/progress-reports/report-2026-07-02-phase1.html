החלטות ארכיטקטורה מאושרות

Tauri v2 — לא Electron, לא browser-only

אפליקציה native ~6MB, cross-platform (Windows/Mac/Linux), Rust shell + React WebView. Python sidecar אינו מבונדל — Tauri מפעיל את מה שהלקוח כבר התקין דרך pip install.

Token flow: stdout → Rust → TypeScript

Python מדפיס READY token=<64-hex> ל-stdout. Rust קורא, שומר ב-managed state. Frontend מקבל דרך Tauri command get_ws_credentials(). Token לא נוגע לדיסק ולא מוטמע ב-bundle.

WebSocket ownership — Panel בלבד

Panel window מחזיק את ה-WebSocket connection. Bubble מקבל events דרך Tauri IPC (emit/listen). מונע double-auth על server שמקבל client אחד בלבד.

State management — Zustand + derived selectors

activityLevel הוא derived selector, לא field: BLOCKED אם gate פתוח, ATTENTION אם diff מוכן, THINKING אם מנוע רץ, IDLE אחרת. Bubble רושם רק ל-selector הזה — לא מתרנדר על כל event.

סיכונים מזוהים
סיכון חומרה מיטיגציה
inbound protocol gaps — user.command/user.cancel לא קיימים בsidecar גבוה מסכמים את החוזה לפני פאזה 3. רק 4 types מאומתים.
Cross-window WS ownership — double-auth גבוה Panel בלבד מחזיק socket. Bubble מקבל events דרך IPC בלבד.
Orphan Python process ב-Windows על force-quit בינוני SIGTERM + taskkill ב-sidecar.rs. חובה לבדוק עם force-quit, לא רק סגירה נקייה.
Token length — 64 hex chars, לא 32 נמוך לא לhardcode. parse מה-READY line.
