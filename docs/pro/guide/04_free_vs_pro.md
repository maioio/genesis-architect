## The integrity rule (non-negotiable)

All paid-tier depth lives in the **private `genesis-architect-pro`** package. The
public free core **never** contains Pro engine code — only the bridge that
detects and lights up Pro when it is installed and licensed, plus documentation
that *describes* Pro behavior. This is checked, not assumed.

## The upgrade reason, in one line

**Developer Field Intelligence + Recovery** — the two things Free cannot do at
all — plus the cross-source Knowledge Graph that nothing else on the market has.
