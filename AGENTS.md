# AGENTS.md

Vendor-neutral guidance for any coding agent (or human) working in this repository.
Claude Code reads [CLAUDE.md](CLAUDE.md), which points here. The Claude skill itself is
[SKILL.md](SKILL.md). Roles:

| File | Role |
|---|---|
| `AGENTS.md` | How to work in this repo. Applies to every agent. |
| `CLAUDE.md` | Claude Code specifics only. Imports this file. |
| `SKILL.md` | The product's runtime workflow when Genesis runs as an agent skill. Not a contributor guide. |

## What Genesis is

Genesis Architect is a Python CLI (`genesis`) and agent skill. `genesis init` researches public
GitHub projects and scaffolds a new project; `genesis recover .` analyses an existing codebase
(import graph, anti-patterns, architecture score) without editing its source. AGPL-3.0-or-later,
Python 3.11+. Stable line: 9.x. No paid tier.

## Canonical facts

Version, engine and gate counts, architecture score, cycle count, and test count are never typed
by hand. The chain is:

`pyproject.toml` and `ARCHITECTURE_INVARIANTS.json` -> `data/public-product-facts.json` ->
README facts block and site.

If prose disagrees with `data/public-product-facts.json`, the prose is wrong. Do not copy a
number into a doc; link to the facts file or the site.

## Generated or source-owned: how to treat files

| File | Rule |
|---|---|
| `data/public-product-facts.json` | Generated. `python scripts/public_surface/generate_product_facts.py` (check mode: `--check`). |
| README block between `<!-- facts:start -->` and `<!-- facts:end -->` | Generated. `python scripts/public_surface/sync_readme_facts.py`. |
| `ARCHITECTURE_INVARIANTS.json` | Generated. `python scripts/architecture_invariants.py` (check mode: `--check`). |
| `ARCHITECTURE_EVIDENCE.md` | Generated by `scripts/evidence_pack.py`. Do not hand-edit. |
| `demo/output/` | Generated by `demo/run_recover.py`. |
| `FRAGILITY_MAP.md`, `.genesis/` | Output of `genesis recover` on a project. Never commit these from a working checkout. |
| `site/package-lock.json`, other lockfiles | Change only through the package manager. |

## Commands

Setup: `pip install -e ".[dev]"`. Run the CLI from source with `PYTHONPATH=src python -m genesis_architect.cli_entry ...`
if the package is not installed.

Always set `GENESIS_NO_AUTO_INSTALL=1`. The test suite must never install anything.

Before and after a change:

```bash
pytest -q
python scripts/architecture_invariants.py --check
python scripts/public_surface/generate_product_facts.py --check
python scripts/public_surface/sync_readme_facts.py --check
python scripts/public_surface/validate_public_claims.py
python demo/run_recover.py --check
python scripts/eval_runner.py --mode validate
git diff --check
```

If you touched `site/` or public docs, also: `cd site && npm ci && npm run build`, then
`python scripts/public_surface/validate_site_build.py`.

## Testing expectations

- A behavior change ships with a test. A bug fix ships with a regression test.
- Tests run on Python 3.11, 3.12 and 3.13.
- Tests must not touch the network or install packages.
- Scaffold output is smoke-tested over 8 language/tier combinations; keep that passing.
- Package data must ship in the wheel.

## Security and write boundaries

- `recover` and the MCP tools never edit the analysed project's source. Genesis writes only its
  own outputs (`.genesis/`, `FRAGILITY_MAP.md`, reports) into the project directory.
- Analysed code is parsed (AST), never executed.
- Mutating commands are dry-run by default; `--apply` is the only consent switch.
- Do not print, log or commit secrets. Credential files are excluded by `.gitignore`.
- Details: [SECURITY.md](SECURITY.md) and [docs/security/](docs/security/).

## Public claim rules

- Every public number comes from the facts file. CI rejects drift.
- No claim of a capability that is not shipped. Planned work is labelled planned.
- No em dashes or en dashes in reader-facing docs.
- Keep SKILL.md under 480 lines.
- Do not invent evidence, benchmarks, or comparisons. If it was not measured, say so.

## Do not edit blindly

`SKILL.md` (behavioral contract, line cap), `pyproject.toml` (version and packaging; the version
feeds the facts chain), `.github/workflows/` (SHA-pinned actions, branch protection depends on
job names), `.gitleaks.toml`, `.lychee.toml`, `CODEOWNERS`, anything under `genesis-architect-pro/`.

## PRE-v10 and v10

`main` is the stable 9.x line. PRE-v10 and the `genesis-vnext` work live outside `main` and
must not be merged, implemented or modified from a repo-hygiene change. Do not describe v10
behavior as current anywhere. See [docs/reference/versioning.md](docs/reference/versioning.md).

## Release boundaries

Agents do not publish to PyPI, create GitHub Releases, push tags, change repository settings,
or merge to `main`. Those are owner actions. Prepare the change, show the exact command, stop.
