הדגשים הארכיטקטורים

Token flow — stdout בלבד

Python מדפיס READY token=<64-hex>. Rust קורא מ-stdout (לא מקובץ, לא env var). Frontend מקבל דרך get_ws_credentials(). Token לא נוגע לדיסק לעולם.

Orphan protection

Rust שומר Child handle. על RunEvent::ExitRequested — קורא kill_sidecar(). Windows: taskkill /F. Unix: SIGTERM + 500ms + kill. בדיקה עם force-quit חובה לפני release.

Bubble ↔ Panel — IPC, לא WebSocket כפול

Panel מחזיק את ה-WebSocket. אחרי כל event שמגיע ל-Panel, הוא עושה app.emit("genesis://event", ...). Bubble מאזין דרך listen() של Tauri — מונע double-auth.

activityLevel — derived, לא stored

selectActivityLevel(state) הוא selector טהור. Bubble מרשם רק אליו — לא מתרנדר על כל engine event. 0 re-renders מיותרים.
