מה הולך עכשיו — מהקל לקשה

  • App Icons — כל הגדליםמייצר את כל ה-PNG sizes הנדרשים (16–1024) + ICO לWindows + ICNS למ macOS מהלוגו הקיים. כותב ל-src-tauri/icons/.
  • tauri.conf.json — icons + bundle configמגדיר את bundle.icon, identifier, productName, version. הכנה לbuild נקי.
  • tauri-plugin-updater — auto-updateמוסיף plugin לCargo.toml + lib.rs, מגדיר pubkey, יוצר latest.json endpoint structure.
  • GitHub Actions — matrix buildworkflow שמבנה Windows MSI / macOS DMG / Linux AppImage על כל push ל-pro/main. Artifacts מועלים ל-GitHub Releases.
  • VS Code Extension — publish pipelinevsce package → .vsix artifact. אופציונלי: vsce publish למארקטפלייס (דורש PAT).
  • Code Signing — WindowsAuthenticode: דורש EV cert ($300-700/yr) או self-signed עם SmartScreen warning. נגדיר placeholder + הנחיות.
  • Code Signing — macOS notarizationדורש Apple Developer account ($99/yr) + notarytool. נגדיר את ה-workflow ללא cert, עם הנחיות לאחר רכישה.
