מה נשאר (דורש פעולה ממך)

  • 🔑 החלפת pubkey ב-tauri.conf.json הרץ npx tauri signer generate -w ~/.tauri/genesis-companion.key, העתק את ה-pubkey לשדה plugins.updater.pubkey
  • 🎨 החלפת app icons בלוגו Genesis האמיתי כרגע icons הם ה-default של Tauri. הכנס את genesis_architect_blue_300dpi.png, הרץ npx tauri icon path/to/logo.png לייצור כל הגדלים אוטומטית.
  • 📦 פתיחת publisher account ב-VS Code Marketplace publisher: "genesis-pro" ב-package.json. צור account ב-marketplace.visualstudio.com/manage, קבל PAT, הוסף VSCE_PAT לGitHub Secrets.
  • 🏪 Windows Authenticode cert (לפני GA) $300-700/yr מ-DigiCert/Sectigo. ללא זה: SmartScreen יציג "Unknown Publisher". לא חוסם הפצה, רק UX.
  • 🍎 Apple Developer Program (לפני macOS launch) $99/yr. דרוש ל-Gatekeeper pass. ללא זה: "unidentified developer" dialog. הוראות מלאות ב-companion/docs/code-signing.md.
